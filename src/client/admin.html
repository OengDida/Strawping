Setup

Setup guide

  1. In Telegram, open @BotFather, send /newbot, and follow its prompts. Keep the bot token private.
  2. Open a chat with your new bot and press Start or send /start.
  3. Get your numeric Telegram chat ID using a trusted chat-ID bot, or from your bot's updates after sending it a message.
  4. In your hosting dashboard, open project settings → Environment Variables. Add TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID.
  5. Save the variables and trigger a new deploy so the function uses the updated configuration.
  6. Return here and click Test Telegram Ping. The recipient must have started the bot first.

Never paste the token into this page, browser storage, GitHub, or chat. If exposed, revoke it through BotFather and replace the server environment variable.

Security

Database access is server-managed

The storefront and admin use the secured server API.

  • Apply the reviewed database/schema.sql from your project repository in the Supabase SQL Editor.
  • Keep Row Level Security enabled. Do not add broad policies that grant access to anon or authenticated.
  • Store SUPABASE_URL and SUPABASE_SERVICE_ROLE_KEY only in server environment variables. Never enter them into a browser form or commit them to Git.
  • The service-role key bypasses RLS. Treat it as a secret and rotate it immediately if it has been exposed.
